### 📄 INÍCIO DA ORDEM DE SERVIÇO RÁPIDA

**OS-011: Telemetria de Executores na Rota de Pesquisa**
**Prioridade:** Alta (Observabilidade)
**Alvo:** `agentic_api/schemas.py` e `agentic_api/routes.py`

**Contexto da Missão:**
A rota `/search_and_fetch` está omitindo qual executor (ex: `L0-aiohttp`) foi utilizado para raspar cada URL. Essa informação já existe no Worker (pois a rota `/fetch` a exibe), mas esquecemos de repassá-la para o contrato de saída dos múltiplos resultados da pesquisa.

**Objetivo:**
Garantir que cada item dentro da lista `results` do JSON final reporte exatamente qual executor obteve sucesso na extração daquela URL específica.

#### Passo 1: Atualização do Contrato (`schemas.py`)

Adicione o campo `executor_used` ao modelo que representa cada item individual da resposta.

```python
class SearchResultItem(BaseModel):
    url: str
    executor_used: Optional[str] = None  # <-- NOVO: Rastreio de qual motor operou nesta URL
    semantic_chunks: List[dict]
    markdown_body: Optional[str] = None

```

#### Passo 2: Mapeamento no Roteador (`routes.py`)

Dentro do loop onde a rota `/search_and_fetch` processa o resultado do `run_dataclear_job` (ou do Worker), extraia a chave `executor_used` e passe-a para o modelo.

```python
# No momento de instanciar o SearchResultItem, puxe o executor_used do dicionário do Worker:
resultado = SearchResultItem(
    url=url_descoberta,
    executor_used=resultado_do_worker.get("executor_used", "unknown"),  # <-- NOVO: Captura o relatorio do trator
    semantic_chunks=chunks_do_worker,
    markdown_body=texto_bruto if request.include_raw else None
)

```

#### Critérios de Aceite:

No teste local, ao inspecionar o array `results` da rota `/search_and_fetch`, cada bloco deve conter a chave `"executor_used": "L0-aiohttp"` (ou o nome do executor correspondente) logo abaixo da `url`.
