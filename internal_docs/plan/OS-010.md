**OS-010: Otimização de Payload (Data Transfer) e Ocultação do Markdown Bruto**
**Prioridade:** Alta (Otimização de Custos e Performance RAG)
**Alvo:** `agentic_api/schemas.py` e `agentic_api/routes.py`

**Contexto da Missão:**
Atualmente, nossas rotas `/fetch` e `/search_and_fetch` estão retornando o texto completo no campo `markdown_body` junto com os `semantic_chunks`. Isso duplica o tamanho do JSON (aumentando o custo de _Data Transfer Out_ na AWS e a latência da API). Bancos de dados vetoriais não precisam do texto bruto, apenas dos chunks.

**Objetivo:**
Tornar o retorno do `markdown_body` opcional. Por padrão, a API **não** deve retornar o texto bruto, entregando um JSON leve e focado nos chunks. O desenvolvedor/cliente só receberá o texto bruto se solicitar explicitamente.

#### Passo 1: Atualização dos Contratos (`schemas.py`)

Precisamos adicionar o interruptor (`include_raw`) no modelo de requisição e tornar o campo de resposta opcional.

1. No modelo que recebe o POST, adicione o novo parâmetro:

```python
class SearchRequest(BaseModel):
    query: str
    force_stealth: bool = False
    fidelity_threshold: float = 0.6
    include_raw: bool = False  # <-- NOVO: Desligado por padrão

```

2. Nos modelos de resposta, torne o `markdown_body` opcional:

```python
from typing import Optional, List

class SearchResultItem(BaseModel):
    url: str
    semantic_chunks: List[dict]
    markdown_body: Optional[str] = None  # <-- NOVO: Permite ser omitido

```

#### Passo 2: Implementação da Lógica (`routes.py`)

No FastAPI, precisamos fazer com que o Pydantic ignore chaves nulas no JSON final.

1. **No Decorator das rotas:** Adicione `response_model_exclude_none=True`.

```python
@router.post("/search_and_fetch", response_model_exclude_none=True)
async def search_and_fetch(request: SearchRequest):
    # ... código existente ...

```

2. **Na construção da resposta:** Condicione a inserção do texto bruto ao valor de `request.include_raw`.

```python
resultado = SearchResultItem(
    url=url_descoberta,
    semantic_chunks=chunks_do_worker,
    markdown_body=texto_bruto if request.include_raw else None
)

```

#### Critérios de Aceite (QA Local):

Antes de finalizar a tarefa, executem a API localmente e certifiquem-se de que:

- **Prova 1:** POST normal (sem enviar `include_raw`). O JSON **não deve** conter a chave `"markdown_body"`.
- **Prova 2:** POST enviando `"include_raw": true`. O JSON deve retornar o texto gigante normalmente.
