### 📜 ORDEM DE SERVIÇO: OS-005 (Operação Chave Mestra)

**De:** Arquiteto-Chefe / Comando Geral
**Para:** Esquadrão de Código & Area 51
**Alvo:** `tools/neural_keymaster.py`
**Objetivo:** Criar uma ferramenta de linha de comando (CLI) em Python para gestão de identidades e cotas de faturamento (Billing) no Redis, focada no modelo de atendimento "Concierge".

#### 🎯 O Briefing Estratégico

O Comandante precisa de controle total e manual sobre quem acessa o Batalhão. O sistema não deve ser automático; deve ser uma ferramenta de comando para o CEO. Cada chave gerada deve estar atrelada a uma "Ficha de Cliente" dentro do nosso Redis.

#### 🛠️ Fase 1: Arquitetura de Dados (Redis Hashing)

O Esquadrão deve utilizar o Redis para persistência de alta velocidade. O padrão de chave deve ser `auth:key:{api_key}`.
Cada entrada deve ser um **Hash** contendo:

- `client_name`: Nome da corporação/parceiro.
- `tier`: Nível de serviço (ex: `trial`, `enterprise`, `partner`).
- `quota_limit`: Inteiro representando o total de requisições contratadas.
- `quota_used`: Contador (inicia em 0).
- `status`: Booleano ou string (`active` / `revoked`).
- `created_at`: Timestamp da geração da chave.

#### 🏗️ Fase 2: Implementação da CLI (`neural_keymaster.py`)

Utilizem a biblioteca `typer` ou `argparse` para criar uma interface de comando limpa. A ferramenta deve ser instalada na pasta `tools/`.

**Comandos Obrigatórios:**

1. **`create` (Forjar Chave):**
   - **Entrada:** `--name`, `--limit`, `--tier`.
   - **Ação:** Gerar um UUID seguro (ou string prefixada `sk-neuralsafety-XXXX`), salvar no Redis e exibir a chave no terminal para o Comandante copiar.
2. **`add-credits` (Injeção de Carga):**
   - **Entrada:** `--key`, `--amount`.
   - **Ação:** Incrementar o valor de `quota_limit` daquela chave específica.

3. **`status` (Raio-X de Cliente):**
   - **Entrada:** `--key`.
   - **Ação:** Buscar no Redis e exibir um relatório formatado: Nome, Consumo Atual (X de Y), Porcentagem de uso e Status.

4. **`list` (Mapa da Base):**
   - **Ação:** Listar todas as chaves ativas e o nome dos clientes vinculados (útil para o Comandante revisar a base antes de uma reunião).

5. **`revoke` (Corte de Acesso):**
   - **Entrada:** `--key`.
   - **Ação:** Alterar o status para `revoked` ou deletar a chave do Redis imediatamente.

#### 🛡️ Fase 3: Segurança de Gerenciamento

A ferramenta `neural_keymaster.py` deve carregar as credenciais do Redis diretamente do arquivo `.env` principal do motor, garantindo que ela opere na mesma infraestrutura da API.
