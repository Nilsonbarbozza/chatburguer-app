**Contexto:**
Nossa API está sendo enganada por sites modernos (SPAs) que retornam 200 OK, mas com uma "casca HTML" vazia. Precisamos implementar o código de autópsia de dados (projetado pelo Eng. #### 1. Sítio Alpha: Refatoração de Armamento (Headers Dinâmicos)

**Arquivo:** `core/executors/executor_l0_aiohttp.py` (e correlatos como o `curlcffi`)
**Ação:** Desvincular os headers hardcoded para permitir a injeção do disfarce do Googlebot.

_Modifique a inicialização da classe/função para aceitar headers:_

```python
# Adicione a constante do disfarce no topo do arquivo ou em um config:
GOOGLEBOT_HEADERS = {
    "User-Agent": "Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)",
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8"
}

# Na inicialização do ClientSession:
def __init__(self, timeout=30, custom_headers=None):
    # Se nenhum header for passado, usa o Googlebot por padrão para forçar SSR nos alvos!
    headers_to_use = custom_headers if custom_headers else GOOGLEBOT_HEADERS

    self.session = aiohttp.ClientSession(
        timeout=timeout,
        headers=headers_to_use
    )

```

#### 3. Sítio Charlie: O Gatilho do Fantasma (Auto-Escalonamento)

**Arquivo:** `agentic_api/routes.py`
**Ação:** O cliente não pode receber 0 chunks. Se o L0 falhar miseravelmente (HTML vazio e sem cofres secretos), o `routes.py` assume o erro e tenta novamente usando o Playwright antes de devolver o JSON final.

_No endpoint da rota, logo após o processamento inicial:_

```python
# Execução normal com a infantaria leve (L0/L12):

clear_result = await loop.run_in_executor(process_pool, run_dataclear_job, html_content)

# O GATILHO FANTASMA (Auto-Healing)

# Se os chunks estão vazios ou o texto total extraído for menor que 300 caracteres:
```
