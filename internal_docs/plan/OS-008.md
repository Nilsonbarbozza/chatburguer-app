### 📜 ORDEM DE SERVIÇO: OS-008 (Operação Blindagem de Escala)

**De:** Arquiteto-Chefe / Comando Geral
**Para:** Esquadrão de Código
**Alvos:** `agentic_api/auth.py`, `agentic_api/routes.py`, `core/coordinator.py`
**Objetivo:** Implementar tarifação dinâmica por nível de extração e escudo contra Efeito Manada (Deduplicação), mantendo a resposta HTTP estritamente síncrona para consumo por LLMs.

#### ⚠️ O Briefing Técnico (Veto de Polling)

Atenção, Esquadrão: a proposta de retornar um `job_id` e exigir _Polling_ (ficar perguntando se o texto está pronto) foi **vetada pelo Comando**. Nosso produto é uma ferramenta para Agentes de IA (Function Calling). O LLM do cliente precisa do Markdown na mesma requisição HTTP. O _DataClear_ continuará rodando em `ProcessPoolExecutor` para isolar a CPU, mas a resposta da API permanecerá síncrona.

#### 💰 Fase 1: O Motor Financeiro Dinâmico

Não cobramos mais 1 crédito fixo por requisição. O custo agora é atrelado ao poder de fogo exigido pela missão.

1. **Tabela de Custos:**
   - L0 (aiohttp - Rápido/Leve): **1 Crédito**
   - L12 (curl_cffi - TLS Spoofing): **3 Créditos**
   - L34 (Playwright - Renderização JS pesada): **10 Créditos**
2. **A Lógica de Cobrança (`auth.py` / `routes.py`):**
   - A cobrança deve ocorrer **antes** de acionar o Batalhão (use `HINCRBY` passando um valor negativo ou incrementando o uso conforme a tabela acima).
   - **Mecanismo de Reembolso (Refund):** Toda rota de captura deve ser envolvida em um bloco `try/except`. Se o trator falhar miseravelmente (ex: timeout absoluto ou erro interno nosso), o bloco `except` deve invocar uma função de reembolso que devolve os créditos do cliente antes de disparar o `HTTP 500`. Nós não cobramos por falhas do nosso motor.

#### 🛡️ Fase 2: O Escudo Anti-Manada (Mutex Síncrono)

Vamos proteger nosso IP de proxy e CPU contra dezenas de requisições simultâneas para o mesmo site.

1. **A Chave de Bloqueio (Redis Lock):**
   - Quando uma requisição para `domain.com` entrar, criem uma variável `lock_key = f"lock:capture:{domain}"` e um `cache_key = f"cache:capture:{domain}"`.
   - Usem `redis.set(lock_key, "1", nx=True, ex=30)`.
2. **Fluxo do Vencedor (Quem pegou o Lock):**
   - Se o `set` retornar `True`, esta requisição aciona o Batalhão (L0/L12/L34).
   - Após limpar o HTML, salva o Markdown final no `cache_key` com expiração de 5 minutos e devolve a resposta no FastAPI.
3. **Fluxo dos Clones (Quem não pegou o Lock):**
   - Se o `set` retornar `False`, significa que outro Batalhão já está raspando aquele site _neste exato segundo_.
   - **A Mágica Síncrona:** O código não deve devolver um erro. Ele deve entrar em um loop assíncrono não-bloqueante (`await asyncio.sleep(0.5)`), checando o `cache_key` a cada meio segundo. Assim que o Batalhão "Vencedor" salvar o resultado, os clones pegam do cache e respondem todos de uma vez aos seus respectivos clientes.

### 🎯 Definition of Done (Critérios de Aceite)

1. Disparar uma missão nível L34 debita 10 créditos no painel do Keymaster. Se o servidor for derrubado no meio da missão, os 10 créditos voltam.
2. Disparar 50 requisições simultâneas para a mesma URL via Postman resulta em **apenas 1 log de execução** no terminal do Batalhão, mas as 50 telas do Postman recebem o Markdown perfeito ao mesmo tempo.
